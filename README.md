# Sales Data Cleaning and Analysis Using Excel

## 📌 Project Overview

This project focuses on cleaning, analyzing, and visualizing a retail sales dataset containing 1000 customer orders using Microsoft Excel.

## 🎯 Objectives

* Clean and prepare messy sales data
* Handle missing values and duplicates
* Perform sales calculations
* Analyze sales using Pivot Tables
* Create charts and a summary dashboard

## 🛠 Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Conditional Formatting
* Charts

## 📊 Tasks Performed

* Removed duplicate records
* Handled missing values
* Fixed inconsistent formatting
* Calculated Total Sales using formulas
* Applied conditional formatting
* Created Region-wise, Category-wise, and Monthly Sales Pivot Tables
* Created Bar, Pie, and Line charts
* Built a Sales Dashboard

## 📈 Key Analysis

* Total Sales
* Average Order Value
* Highest Order Value
* Top 5 Products by Revenue
* Region-wise Sales Performance
* Monthly Sales Trend

## 📂 Project Files

* `sales_data_raw.xlsx` – Original raw sales dataset
* `sales_data_cleaned.xlsx` – Cleaned and analyzed sales data
* `dashboard.png` – Final Excel sales dashboard
